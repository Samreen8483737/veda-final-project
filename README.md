# E-Commerce Customer Segmentation (RFM Analysis) 🛒📊

**Role:** Data Science Intern @ Veda Technologies
**Tech Stack:** Python, Pandas, Scikit-learn (K-Means), Power BI

## Project Objective
Leveraged a transactional dataset of 4,300+ customers to build an automated RFM (Recency, Frequency, Monetary) segmentation pipeline. 

## Methodology
1. **Data Engineering:** Cleaned transactional data and engineered Recency, Frequency, and Monetary features using Pandas.
2. **Machine Learning:** Standardized features and applied K-Means clustering to identify four optimal customer segments.
3. **Data Visualization:** Exported the clustered dataset to Power BI to build interactive scatter plots and KPI dashboards.
4. **Actionable Insights:** Mapped algorithmic clusters to business segments (Champions, At-Risk, Promising, Lost) and drafted targeted marketing campaigns to maximize ROI.
